# M6-L2 – Säuren, Basen und Oxidationsstufen {#L2}

**Kursbereich:** M6 – Anorganische Chemie der Hauptgruppen

**Niveau:** Bachelor

**Vorwissen:** [M6-L1](M6-L1.md).

**Lernziel:** Brønsted- und Lewis-Säuren sowie formale Oxidationszahlen bei Hauptgruppenverbindungen unterscheiden.

## Zwei Säure-Base-Konzepte {#S1}
Eine Brønsted-Säure überträgt ein Proton, eine Brønsted-Base nimmt es auf. Eine Lewis-Säure akzeptiert ein Elektronenpaar, eine Lewis-Base stellt es für eine Bindung bereit. Das Lewis-Konzept umfasst auch Reaktionen ohne Protonenübertragung. Oxide elektropositiver Metalle zeigen häufig basischen Charakter, viele Nichtmetalloxide sauren Charakter. Amphoterie bedeutet, dass eine Substanz je nach Reaktionspartner sowohl sauer als auch basisch reagieren kann. Struktur, Löslichkeit und Medium beeinflussen die Beobachtung.
## Oxidationszahlen als Bilanz {#S2}
Oxidationszahlen werden durch formale Zuordnung der Bindungselektronen bestimmt. Die Summe entspricht der Gesamtladung. Sauerstoff wird meist −II zugeordnet, in Peroxiden −I; Wasserstoff meist +I, in vielen Metallhydriden −I. Eine Oxidationszahl ist keine gemessene Partialladung. In einem Oxoanion kann das Zentralatom trotz hoher formaler Oxidationszahl kovalent gebunden sein.
## Beispiel {#S3}
In Sulfat SO₄²⁻ gilt x + 4(−2) = −2, daher x = +6. In Sulfit SO₃²⁻ gilt x + 3(−2) = −2, also x = +4. Der formale Übergang von Sulfit zu Sulfat entspricht einer Oxidation um zwei Elektronen pro Schwefelatom. Eine vollständige Reaktionsbilanz benötigt zusätzlich einen passenden Reduktionspartner.

## Grenzen und typische Fehler {#S4}

Oxidationszahl, Formalladung und Partialladung unterscheiden.
